# Support

Use this repository for public Syntalume support.

## Before Opening An Issue

1. Update Syntalume from the VS Code Marketplace.
2. Reload VS Code.
3. Run `Syntalume: Doctor`.
4. Check [Troubleshooting](docs/troubleshooting.md).

## Useful Details

Please include:

- Syntalume version.
- VS Code version.
- Operating system.
- Active color theme, file icon theme, and product icon theme.
- Whether you used `Syntalume: Apply Recommended Experience` or another profile.
- Output from `Syntalume: Doctor`, if relevant.
- A screenshot when the issue is visual.

## Security Reports

Do not open a public issue for suspected vulnerabilities. See [SECURITY.md](SECURITY.md).
