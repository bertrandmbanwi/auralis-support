# Support

Use this repository for public Syntalume support.

## Before Opening An Issue

1. Update Syntalume from the VS Code Marketplace.
2. Reload VS Code.
3. Run `Syntalume: Doctor`.
4. Check [Troubleshooting](docs/troubleshooting.md).

## Useful Details

Please include:

- Syntalume version.
- VS Code version.
- Operating system.
- Active color theme, file icon theme, and product icon theme.
- Whether you used `Syntalume: Apply Recommended Experience` or another profile.
- Output from `Syntalume: Doctor`, if relevant.
- A screenshot when the issue is visual.

## Private Preview

Want to help test the next Auralis release in a real editor workflow? Read the
[private-preview guide](docs/private-preview.md), then use the
[volunteer form](https://github.com/syntalume/syntalume-support/issues/new?template=private_preview.yml).

After testing, use the
[preview feedback form](https://github.com/syntalume/syntalume-support/issues/new?template=preview_feedback.yml).
Both forms create public GitHub issues. Do not include contact information,
private code, unreleased names, screenshots, files, or download links.

## Security Reports

Do not open a public issue for suspected vulnerabilities. See [SECURITY.md](SECURITY.md).
