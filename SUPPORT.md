# Support

Use this repository for public Auralis support.

## Before Opening An Issue

1. Update Auralis from the VS Code Marketplace.
2. Reload VS Code.
3. Run `Auralis: Doctor`.
4. Check [Troubleshooting](docs/troubleshooting.md).

## Useful Details

Please include:

- Auralis version.
- VS Code version.
- Operating system.
- Active color theme, file icon theme, and product icon theme.
- Whether you used `Auralis: Apply Recommended Experience` or another profile.
- Output from `Auralis: Doctor`, if relevant.
- A screenshot when the issue is visual.

## Security Reports

Do not open a public issue for suspected vulnerabilities. See [SECURITY.md](SECURITY.md).
