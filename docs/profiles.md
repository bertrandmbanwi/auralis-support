# Themes and Profiles

Auralis ships eight calibrated themes:

- Auralis Noir
- Auralis Frost
- Auralis Paper
- Auralis Botanica
- Auralis Noir High Contrast
- Auralis Frost Colorblind
- Auralis Paper Contrast
- Auralis Dimmed

## Complete Experience Profiles

Profiles apply a coherent setup instead of only changing colors.

- `Auralis Botanica: Calm Infra`: recommended first-run profile for Terraform, YAML, and cloud infrastructure.
- `Auralis Noir: Deep Work`: cinematic dark mode for long coding sessions.
- `Auralis Frost: Systems`: crisp technical dark mode.
- `Auralis Paper: Daylight`: warm light mode.
- `Auralis Review Lens`: review and diff-heavy workflow.
- `Auralis Terminal Heavy`: low-glare terminal-heavy setup.
- `Auralis AI Pairing`: inline suggestions, hints, chat, and generated edit contrast.

Run:

```text
Auralis: Apply Complete Experience
```
